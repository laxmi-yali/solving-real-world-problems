# solving-real-world-problems
6 Real-World Problems Using Python

📌 About the Project

This repository contains 6 real-world problems solved using Python programming. It is designed for beginners to improve their coding skills and logical thinking through practical examples.

🎯 Objectives

Learn Python programming basics.

Practice conditional statements and loops.

Understand lists and dictionaries.

Develop problem-solving skills.

Apply Python to real-world situations.

** Problems Included

Student Marks and Grade Calculator

ATM Withdrawal System

Attendance Percentage Calculator

Password Attempt System

Hospital Patient Temperature Monitor

Classroom Seating Arrangement
